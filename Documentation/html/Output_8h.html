Writes webs and register assignments to the output file required by the statement.

If allocation succeeds, each web is printed with either rX for its register or M for memory. If allocation fails, the number of registers is written as zero and every web is assigned to memory.

Parameters
filenamePath to the output allocation file.
websOriginal webs produced before allocation.
colorResultResult returned by the selected coloring algorithm.
Time Complexity: O(W log W + P + A), where W is the number of webs, P is the total number
of program points printed and A is the number of assignments in the coloring map.
