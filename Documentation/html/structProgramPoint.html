Detailed Description

One program point in a live range or web.

A + marker in the input sets isStart, and a - marker sets isEnd. A point may have neither marker when it is only an intermediate point in the live range. During web merging, a point that is both start and end is normalized to an interior point because it represents a fused self-assignment boundary such as i = i + 1.
