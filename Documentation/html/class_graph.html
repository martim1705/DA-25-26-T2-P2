Detailed Description

template<class T>
class Graph< T >

Generic directed graph represented by adjacency lists.

The interference graph is stored as a Graph<Web> with one vertex per live web and bidirectional edges for interference. The class owns all vertices and edges.

Template Parameters
TType stored in each vertex.
