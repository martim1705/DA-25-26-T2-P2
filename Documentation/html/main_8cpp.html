Program entry point.

With no arguments, launches the interactive menu. In batch mode, expects the statement-compatible syntax -b <ranges.txt> <registers.txt> <allocation.txt>.

Parameters
argcNumber of command-line arguments.
argvCommand-line argument vector.
Returns
0 on success, 1 on argument/menu errors and 2 when allocation is infeasible.
Time Complexity: O(runAllocation) in batch mode and O(number_of_menu_runs * runAllocation) in interactive mode.
