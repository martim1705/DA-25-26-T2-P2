std::vector< Web > buildWebs ( const std::vector< LiveRange > &  ranges)

Builds live webs by merging live ranges of the same variable that share at least one program point.

Ranges are first grouped by variable. For each variable, a greedy closure is performed: once a range is inserted into the current web, every still-unused range that intersects that growing web is also merged. Points are then sorted and duplicate lines are normalized.

Parameters
rangesRaw live ranges parsed from the input file.
Returns
Vector of normalized webs with consecutive ids.
Time Complexity: O(R^2 * P^2) in the worst case per variable, where R is the number of ranges
of the variable and P is the maximum number of points in a range. The final sorting step costs O(W * Q log Q), where W is the number of webs and Q is the maximum number of points in one web.
